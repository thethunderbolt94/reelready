What a new user sees

The run, start to finish

  1. Open the kit in Claude CodeClaude checks the computer and installs what is missing, with your OK. Mac, Linux or Windows.
  2. Setup reads your websiteColours, fonts and logo come from your own site. You confirm them.
  3. Drop clips, they sortTalking, b-roll, voice notes and photos fly into labelled folders.
  4. Answer a few questionsOptional script, built only from your answers, in your words.
  5. Say “edit these”Cut, verbatim captions, brand overlays, sound.
  6. Approve on one pageEvery AI-written line is a card: approve, edit or reject. Trim, swap a shot.
  7. RenderQA and the brand check pass, then the reel is yours. Nothing is posted.

The seven parts

What each part does, and when it counts as done

Install guide for any OS

1
Docs onlySonnet
  • A per-OS table in INSTALL.md: what Claude installs on macOS, Linux and Windows, and how, always with the user’s OK.
  • Notes Claude reads on Windows: no python3 command, the venv lives in Scripts, npx.cmd, Node 22 or newer, UTF-8, main folder outside OneDrive.
  • It also names the four spots in the scripts that assume a Mac, so Claude patches them on that machine. No Windows code ships in the repo.

Done when a fresh Claude Code on each OS knows exactly what to run from the guide alone.

Brand kit

2
Look laneOpus
  • Setup reads the business website for colours, fonts and logo; the owner confirms each.
  • rr.py fonts downloads the profile’s Google Fonts into assets/fonts.
  • Caption colour comes from the profile, or a recommended one picked from the palette.

Done when setup on a real website fills the profile and the fonts in one pass.

Branded overlays

3
Look laneOpusneeds 2
  • Captions with one emphasis word per group in the display face and the brand accent.
  • Four templates driven by the profile: hook card, note-card lower third, end card with logo and call to action, polaroid frame for a b-roll beat.
  • New style cards H7, L5, O4 and B5 plus one mix. The brand check reads them.

Done when one clip renders in two different brands and both pass the brand check.

Sorter

4
Studio app laneSonnet probes, Opus page
  • rr.py sort reads every clip: length, orientation, shoot day, speech or not, photo or video.
  • Groups: Talking to camera, B-roll, Voice notes, Photos, Too short. Clips move into those folders inside raw footage; every move is logged and rr.py sort --undo puts them back.
  • The Studio app opens on it at session start: thumbnails fly into labelled folders, then settle into a library grid.

Done when 50 mixed clips sort in under a minute and every group looks right by eye.

Review page

5
Studio app laneOpusneeds 4
  • Every AI-written line as a card: approve, edit or reject. Caption fixes and brand choices listed.
  • Preview the draft, trim a cut, swap a b-roll shot from the library, pick hook A or B.
  • Render writes review.json; Claude waits for it and re-renders only what changed.

Done when approve, edit and render work end to end without typing in the chat.

Script by interview

6
Words laneSonnet
  • Five to eight short questions. The script is the owner’s answers in order, never a line Claude wrote.
  • Every beat cites the answer it came from; the script checker fails anything else.
  • Voice-memo path: talk for two minutes, the kit orders your own sentences.

Done when the checker rejects any spoken line that is not in the answers.

Proof and push

7
Claude, after lanesneeds 3, 5 and 6
  • The smoke test grows to cover sorting, overlays and the review file.
  • A README tour with real screenshots of the sorter and the review page.

Done when the smoke test passes and main on GitHub matches it.

Decisions and open questions

What the owner decided

Settled by the owner

  • The kit anyone can use comes first; client work later.
  • Windows is a written guide Claude follows on the user’s machine, not code built here.
  • A review-and-approve page, not a timeline editor.
  • Scripts come from a Q&A in the owner’s own words.
  • Caption colour comes from the brand profile, with a recommended one as fallback.
  • Each part is pushed to main as it lands.

Answered 17 Nov

  1. Mac-only spots stay in code. The Windows guide tells Claude which four spots to patch on the user’s machine.
  2. The sorter moves originals into labelled folders inside raw footage. Nothing is renamed or deleted, every move is logged, and one command puts everything back.
  3. Studio opens on session start: new clips are sorted and the page opens in the browser.
  4. The style guide folds in. One app with three pages: Library, Review, Styles.

Later, not this round: the first client’s package and re-cut demo, built on parts 2, 3 and 6.
